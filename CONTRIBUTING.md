# Contributing

Thanks for wanting to help. LifeDash is developed by one person, and for now it
does **not accept code contributions**: pull requests will be closed without
review. This also keeps the licence simple (see [`LICENSE`](LICENSE)).

What helps a lot:

- **Bug reports.** Open an [issue](https://github.com/antarcorrado/lifedash/issues)
  with the version (LifeDash › About LifeDash), your macOS version or browser, what
  you did, what you expected and what happened. From the Mac, Settings › Copy
  diagnostics puts a technical summary on the clipboard to paste in: it contains
  no task titles, descriptions or amounts.
- **Ideas and requests.** Also as issues: describe the problem you want solved
  rather than only the solution.
- **Security problems.** Never in a public issue: see [`SECURITY.md`](SECURITY.md).

Please do not paste real task data, tokens, recovery keys or screenshots with
private information into an issue.
